## Resumen para implementar en el tab Factura

| Concepto | En Excel | En la app |
|----------|-----------|-----------|
| **Tasa IVA** | N2 = 0.21 (21%) | Campo numérico, default 21 |
| **Tasa descuento %** | N3 = 0 | Campo numérico, default 0 |
| **Incluir descripción en líneas** | S3 = S | Checkbox Sí/No |
| **Filas de artículo** | S4 = 3 | Nº de líneas por defecto en plantilla |
| **Cliente** | S2 = Cliente ID | Se elige en presupuesto/factura (tab Clientes) |
| **Datos empresa (cabecera)** | F2–F7 | Título, dirección, CP/población, email, teléfono |
| **Líneas** | B18:K – Descripción, Precio unit., Cant., Total | Ítems desde tab Ítems (informes_items) |

El cliente se rellena por VLOOKUP desde la hoja CLIENTES; en la app usamos la lista de clientes existente. Las líneas de factura/presupuesto son ítems con precio × cantidad = total. La generación del PDF/Excel desde esta plantilla puede ser una fase posterior; el tab Factura permite configurar los parámetros anteriores.
